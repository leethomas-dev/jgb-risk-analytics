# MEMORY (Streamlit Community Cloud free tier: ~1GB RAM). Measured
# directly, not assumed: streamlit+plotly+pandas+numpy+matplotlib import
# overhead alone is ~150MB; running the full dashboard pipeline (current
# curve, PCA, bootstrap, NS/Svensson fits) against the default 2-year PCA
# window peaks at ~186MB total. Widening that window to the FULL 52-year
# history (13,290 rows) barely moves it, ~185MB -- the curve-history
# matrix itself is small regardless of window length; it's the library
# imports that dominate. So PCA_LOOKBACK_YEARS (app.py, env var
# JGB_DASHBOARD_PCA_LOOKBACK_YEARS) is kept configurable per the project's
# own convention, but isn't actually the load-bearing memory lever a
# "PCA over history is the memory risk" assumption would suggest -- see
# docs/phase_4_7_documentation.md for the full measurement and the caveat
